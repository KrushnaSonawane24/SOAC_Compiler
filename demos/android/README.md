# Android TFLite Deployment Demo

This directory contains instructions for deploying the optimized TFLite model generated by SOAC-v2 to an Android application.

## Prerequisites

1.  Android Studio Giraffe or newer.
2.  Android device running Android 6.0 (API level 23) or higher.
3.  The `model.tflite` file generated by the SOAC-v2 pipeline (found in the artifacts folder).

## Integration Steps

1.  **Add TensorFlow Lite Dependencies**
    Open your `build.gradle` (Module: app) file and add the following dependencies:

    ```gradle
    dependencies {
        implementation 'org.tensorflow:tensorflow-lite:2.14.0'
        implementation 'org.tensorflow:tensorflow-lite-support:0.4.4'
        implementation 'org.tensorflow:tensorflow-lite-metadata:0.4.4'
        implementation 'org.tensorflow:tensorflow-lite-gpu:2.14.0' // Optional: for GPU acceleration
    }
    ```

2.  **Import the Model**
    -   Right-click on the `app` folder in Android Studio.
    -   Select **New > Other > TensorFlow Lite Model**.
    -   Select the `model.tflite` file generated by SOAC-v2.
    -   Click **Finish**.

    This will automatically generate a binding class (e.g., `Model` if your file is named `model.tflite`) and place the file in `src/main/assets`.

3.  **Run Inference (Java Example)**

    ```java
    import com.example.app.ml.Model; // Generated class
    import org.tensorflow.lite.DataType;
    import org.tensorflow.lite.support.tensorbuffer.TensorBuffer;
    import java.nio.ByteBuffer;

    try {
        Model model = Model.newInstance(context);

        // Creates inputs for reference.
        TensorBuffer inputFeature0 = TensorBuffer.createFixedSize(new int[]{1, 224, 224, 3}, DataType.FLOAT32);
        
        // Load data into inputFeature0 (e.g., from a ByteBuffer of a Bitmap)
        ByteBuffer byteBuffer = ...; // Load your image data here
        inputFeature0.loadBuffer(byteBuffer);

        // Runs model inference and gets result.
        Model.Outputs outputs = model.process(inputFeature0);
        TensorBuffer outputFeature0 = outputs.getOutputFeature0AsTensorBuffer();

        // Process output
        float[] scores = outputFeature0.getFloatArray();
        // ... use scores ...

        // Releases model resources if no longer used.
        model.close();
    } catch (IOException e) {
        // TODO Handle the exception
    }
    ```

4.  **Hardware Acceleration (Optional)**
    To use the GPU or NPU (NNAPI), use the `Model.Options` builder when creating the instance:
    
    ```java
    Model.Options options = new Model.Options.Builder()
            .setDevice(Model.Device.GPU) // or Model.Device.NNAPI
            .build();
    Model model = Model.newInstance(context, options);
    ```

## Benchmarking
The SOAC-v2 pipeline ensures the model is optimized for size and latency. You can verify on-device performance using the [TFLite Benchmark Tool](https://www.tensorflow.org/lite/performance/measurement).

```bash
adb shell /data/local/tmp/benchmark_model \
  --graph=/data/local/tmp/model.tflite \
  --enable_op_profiling=true \
  --num_threads=4
```
